# METRICS

Every number PRAHARI claims — on the landing page, in the deck, or on stage — is defined here and
regenerated by `python -m engine.fusion.eval`. Running it twice must produce an identical diff.

**Rule: if a number here disagrees with the slide, fix the slide.** Never the other way round.

Tables are empty until the phase that fills them. An empty cell is honest; a guessed cell is not.

---

## 1. Definitions

| Metric | Definition | Filled by |
|---|---|---|
| **Precision** | Of pairs the system links (`p ≥ τ`), the fraction truly the same actor. | Phase 7 |
| **Recall** | Of pairs that truly are the same actor, the fraction the system links. | Phase 7 |
| **F1** | Harmonic mean of precision and recall. | Phase 7 |
| **False-merge rate** | Of links at `p ≥ τ`, the fraction that are different actors. `1 − precision` at τ, reported separately because it is the number that matters in court. | Phase 7 |
| **Brier score** | Mean squared error of the calibrated probability against the binary label. Lower is better; 0.25 is the coin-flip baseline. | Phase 7 |
| **ECE** | Expected Calibration Error — mean gap between stated confidence and observed accuracy, over 10 equal-width bins. Measures whether "0.84" actually means 84%. | Phase 7 |
| **Coverage** | Of true pairs, the fraction surviving the blocking stage. Caps recall: a pair never blocked can never be scored. | Phase 4 |
| **Freshness** | Seconds since a source's last successful scan. Reported per source by `/sources`. | Phase 2 |
| **Extraction P/R** | Per entity type, on 30 hand-labelled sentences (English + Hinglish). | Phase 3 |
| **Splink m/u** | Trained match/unmatch probabilities per comparison column, from the EM fit. | Phase 4 |

## 2. Fusion — the worked example

**Verified in Phase 1 by direct computation. Frozen as a Phase 7 unit test.**

Deck inputs: `s = [0.78, 0.71, 0.83, 0.69, 0.74]`, `r = [0.9, 0.7, 0.8, 0.5, 0.5]`

| Root | Signal | s | LR = s/(1−s) | r | LR^r |
|---|---|---|---|---|---|
| identity_key | PGP fingerprint | 0.78 | 3.5455 | 0.9 | 3.1240 |
| financial | shared wallet | 0.71 | 2.4483 | 0.7 | 1.8716 |
| infra | infrastructure | 0.83 | 4.8824 | 0.8 | 3.5555 |
| linguistic | writing style | 0.69 | 2.2258 | 0.5 | 1.4919 |
| temporal | posting rhythm | 0.74 | 2.8462 | 0.5 | 1.6871 |

| Quantity | Value |
|---|---|
| `LR_total` | **52.3219** |
| prior odds (blocked pair) | 1 : 10 |
| posterior odds | 5.2322 |
| **`p_raw` (PRAHARI)** | **0.8395** → **0.84** |
| **naive noisy-OR** `1 − Π(1−sᵢ)` | **0.9991** → **0.999** |
| *(naive LR-product, prior 1:1 — not our baseline, see DEC-003)* | *0.9963* |

Acceptance: `0.84 ± 0.01` and `0.999 ± 0.001`.
